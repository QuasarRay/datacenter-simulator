# 14 — Four-hour practice exam

## Schedule

This is an original practice exercise, not recalled exam content. Begin with the preflight complete and all required images/collections available offline.

| Minutes | Task | Required output |
|---|---|---|
| 0–25 | VS Code, shell, SSH; inventory; Navigator | Correct graph, strict SSH, version transcript |
| 25–50 | Git branch and playbook | Commit, staged diff, successful limited run |
| 50–85 | Variables, device facts, filters | Derived peers and normalized interface map |
| 85–110 | Loops, conditions, failure handling; include/import/role | Explicit recovery result and reuse explanation |
| 110–150 | Jinja candidate, netcommon apply and verify | Exact state, kernel routes and 12 sourced pings |
| 150–175 | Backup, inject drift, restore, save/restart | Failed drift gate then recovery/restart passes |
| 175–225 | Credentials, Project, workflow, jobs and CaC | Two CaC recaps, core node statuses, durable backups |
| 225–240 | Review all 23 objectives and evidence | Completed acceptance checklist |

Self-score each objective only when its acceptance artifact exists. A failed negative test, missing backup or unverified restart blocks overall lab acceptance. Finish with `git diff` and the runtime evidence inventory.
